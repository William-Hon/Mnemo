2. WHAT HAS BEEN BUILT & CONFIGURED SO FAR
--------------------------------------------------------------------------------
- Supabase Integration (src/lib/supabase.ts):
  * Upgraded from direct SecureStore to LargeSecureStore: uses @react-native-async-storage/async-storage
    encrypted via aes-js and expo-secure-store for the encryption key (bypassing the 2048-byte limit crash).
  * WebStorageAdapter implemented to support Server-Side Rendering / Metro web bundling without
    throwing "ReferenceError: localStorage is not defined".
  * AppState auto-refresh listener attached for mobile native platforms.

- Authentication & Global State (src/providers/AuthProvider.tsx):
  * React Context provider tracking session, user, and isInitialized.
  * Exports useAuth() hook for consumption across components.

- Route Protection (app/_layout.tsx & app/index.tsx):
  * Dynamic route guarding using useSegments() and useRouter().
  * Unauthenticated users are redirected to /(auth)/sign-in.
  * Authenticated users are redirected to /(tabs)/home.

- Auth Screens & Navigation:
  * app/(auth)/_layout.tsx: Stack layout for auth screens.
  * app/(auth)/sign-up.tsx: Email & password validation, calls supabase.auth.signUp().
  * app/(auth)/sign-in.tsx: Connected to supabase.auth.signInWithPassword().
  * app/(tabs)/settings.tsx: Shows current user email and provides functional Sign Out modal.

- Environment Variables & Database:
  * .env file in root contains valid EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY.
  * Verified connection to Supabase cloud database (haaczqmyqgyqwcuvykuf.supabase.co).
  * Existing tables in cloud: 'journal_entries', 'profiles', 'ocr_usage_events'.
  * .gitignore updated so .env is never committed; !.env.example is tracked.
  * Full TypeScript check (npx tsc --noEmit) passes with 0 errors.

- Important Note on Expo Go on iOS:
  * Apple has frozen the public App Store version of Expo Go at SDK 54.
  * Because this project uses Expo SDK 57, scanning with the App Store's Expo Go app
    produces a version mismatch error.
  * To test on physical iPhone: The user can install the SDK 57 Expo Go build via
    Safari at https://sign.expo.dev using their free Apple ID developer signing.
  * Alternatively, running `npx expo start --web` launches the web preview immediately.
